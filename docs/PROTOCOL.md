# Fixed experiment protocol

Written before model fitting, 8 October 2026. Dataset: UCI Bike Sharing, hourly
Capital Bikeshare observations from 2011–2012. This is retrospective research,
not an operational deployment or a Kaggle competition submission.

## Forecast contract

Predict the total rentals in hour t assuming observations through t−1 are
available. Current-hour weather, casual/registered counts and the current target
are excluded. Calendar features and holiday indicators are assumed known.
Reindex onto a regular hourly grid: absent observations remain missing, not zero.
Lags count clock hours. Unknown inputs receive training-fitted median imputation;
seasonal baselines fall back to the last observed value when their exact lag is
missing. Exclude the first 168 hours and rows with an unobserved target.

The source supplies naive local timestamps, not timezone offsets or release
times. Clock changes and real observation latency are unresolved. Test-period
observations can feed later one-hour forecasts; this is not a fixed-origin
24-hour-ahead or recursive multi-step experiment.

## Three expanding forward tests

| Test period | Model-selection month | Interval-calibration month |
| --- | --- | --- |
| April–June 2012 | February 2012 | March 2012 |
| July–September 2012 | May 2012 | June 2012 |
| October–December 2012 | August 2012 | September 2012 |

Each candidate fits on all eligible rows before the selection month. Select by
selection-month MAE, with ties resolved by the fixed candidate order. Refit the
selected recipe on all rows before the calibration month, calibrate using that
month only, then freeze both model and interval radius for the test quarter.
Training, selection, calibration and testing are chronologically disjoint at
selection time. The refit deliberately includes the former selection month.
Earlier test quarters may become historical training data for later quarters.

Candidates, fixed before seeing results:

1. Last observation (exact hour−1, falling back to last available observation).
2. Daily seasonal naive (hour−24 with the same fallback).
3. Weekly seasonal naive (hour−168 with the same fallback).
4. Standardized Ridge, alpha=1.
5. Standardized Ridge, alpha=100.
6. Histogram gradient boosting, Poisson loss, 15 leaves.
7. Histogram gradient boosting, Poisson loss, 31 leaves.

Both boosting candidates use 200 iterations, learning_rate=0.1,
min_samples_leaf=20, l2_regularization=1, early_stopping=False and seed=42.
Negative point predictions are clipped at zero. All preprocessing is fitted
inside the relevant training partition. No further trials will be selected
using test scores. All candidate selection scores will be retained.

## Intervals and metrics

Use the finite-sample corrected 90th percentile of absolute calibration errors
(order statistic ceil((n+1)*0.90), capped at n) as a constant interval radius.
Lower bounds are clipped at zero. Report observed coverage, mean interval width
and interval score at alpha=0.1, alongside point MAE/RMSE and baseline errors.
These split-conformal-style intervals have **no asserted coverage guarantee**
here: serial dependence and distribution shift violate exchangeability.

Report each quarter and the pooled test rows. The percentage MAE improvement
compares with the strongest *pooled test* naive baseline and is descriptive;
that comparator is not used to choose or train the deployed model. No statistical
significance claim is made from three quarters of one city's data.

## Recovery and provenance

Freeze input archive SHA-256, protocol, source files, configuration and package
versions before fitting. Save each completed candidate and final fold stage
atomically with file hashes. Verify these hashes and prediction replay on
resume. A changed source/configuration/input fails visibly; it requires a new
output directory, not edits to frozen evidence. An interrupted uncommitted
stage may be repeated. Local models are trusted artifacts generated by this
project and are not loaded from arbitrary third parties.
